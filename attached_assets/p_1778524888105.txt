Buatkan aplikasi web FULL-STACK untuk SCALPING MEME COIN di BASE NETWORK dengan spesifikasi berikut:

## 🎯 TARGET SPESIFIK
- Modal: 200.000 Rupiah (~0.04 ETH)
- Target profit per trade: 3-8% (realistis)
- Hold time maksimal: 5-15 menit
- Maksimal posisi bersamaan: 3-4 token
- Minimal win rate untuk profit: 60% (dengan risk-reward 1:1)

## 🛠️ TECH STACK
- Backend: Node.js + Express + TypeScript
- Frontend: React + Vite + TailwindCSS + Framer Motion
- Blockchain: ethers.js v6
- Database: SQLite (via better-sqlite3)
- Real-time: WebSocket (Socket.io)

## 🔧 FITUR WAJIB (Scalping Focus)

### Backend Features:
1. **Token Scanner Cepat**
   - Scan token baru setiap 8 detik
   - Filter: umur < 30 menit, liquidity > $10k, volume 5m > $5k
   - Sumber data: DexScreener API + GeckoTerminal

2. **Scalping Entry Logic**
   ```
   IF momentum_5m > 15% 
   AND volume_spike > 2x average
   AND holders_growth > 20% in 5m
   AND safety_score > 70
   THEN BUY 0.002 ETH
   ```

3. **Exit Strategy (Kunci Scalping)**
   - Take Profit 1: +3% → jual 50%
   - Take Profit 2: +6% → jual 30%
   - Take Profit 3: +10% → jual 20%
   - Stop Loss: -5% → jual semua
   - Trailing Stop: aktif setelah profit >4%, trail 2%

4. **Risk Management untuk Modal 200rb**
   - Per trade: 0.002 ETH (5% modal)
   - Max concurrent: 3 positions
   - Daily loss limit: 0.003 ETH (stop trading 2 jam jika kena)
   - Max slippage: 5% (karena meme coin volatile)

5. **Gas Optimization (Base Network)**
   - Base gas normal: 0.01-0.05 GWEI
   - Set priority fee: 0.002 GWEI
   - Max fee per gas: 0.02 GWEI
   - Biaya per swap: ~$0.002 (cocok untuk scalping kecil)

6. **Safety Check (Wajib!)**
   - Cek honeypot via GoPlus API
   - Cek sell tax < 10%
   - Cek deployer reputation (bukan serial rugger)
   - Cek liquidity terkunci minimal 7 hari

### Frontend Features:
1. **Live Dashboard**
   - Total modal (ETH & Rupiah)
   - Realized PnL hari ini
   - Win rate scalping
   - Rata-rata hold time
   - Running timer

2. **Scalping Control Panel**
   - Tombol START/STOP (warna gradient merah-hijau)
   - Slider risk level (Conservative/Agressive)
   - Toggle Auto Scalping
   - Emergency Stop button

3. **Active Positions Card**
   - Token symbol + age
   - Entry price vs current price
   - Profit % dengan progress bar warna
   - Timer sejak buy (countdown 15 menit)
   - Tombol manual close

4. **Real-time Chart**
   - Lightweight-charts untuk price action
   - Entry/exit markers
   - Order book depth (sederhana)

5. **Trade History Table**
   - Kolom: Time | Token | Entry | Exit | Profit % | Hold Time | Status
   - Filter: Today/This Week/All
   - Export CSV

6. **Log Console**
   - Warna-warni: 🟢 BUY | 🟡 SELL | 🔴 STOP LOSS | ⚪ INFO
   - Scrollable dengan auto-scroll

HAN PREMIUM

### 1. **MEV Protection (WAJIB untuk Scalping)**
**Kenapa penting:** Mencegah bot Anda jadi korban front-running dan sandwich attack yang bisa makan profit kecil Anda.

**Implementasi:** 
Kirim transaksi melalui private relay (QuickNode atau Tatum), bukan public mempool 
```typescript
// Contoh integrasi MEV Protection
const MEV_PROTECTION_RPC = "https://base.mev-protect.tatum.io"
// Transaction otomatis terproteksi, zero config!
```

**Benefit:**
- 400-1000ms lebih cepat block inclusion
- Slippage lebih rendah
- Gas refund jika transaksi gagal 

---

### 2. **TWAP & DCA Order Execution**
**Kenapa penting:** Untuk modal 200rb, membeli sekaligus dalam satu transaksi bisa kena slippage besar. TWAP memecah order menjadi beberapa bagian kecil.

**Fitur:**
- **TWAP (Time-Weighted Average Price)**: Beli 0.002 ETH dipecah jadi 4 transaksi 0.0005 ETH 
- **DCA Auto**: Otomatis beli di harga lebih rendah jika token turun 

```typescript
interface TWAPConfig {
  totalAmount: 0.002,      // Total ETH
  slices: 4,               // Dipecah jadi 4 tx
  intervalSeconds: 30,     // Setiap 30 detik
  maxSlippagePerSlice: 2   // 2% per slice
}
```

---

### 3. **Multi-DEX Aggregator (OpenOcean/Swap aggregator)**
**Kenapa penting:** Harga token bisa beda di Uniswap vs Aerodrome vs BaseSwap. Aggregator cari harga terbaik otomatis.

**Integrasi dengan:** 
- OpenOcean API (agregasi Uniswap, SushiSwap, Aerodrome) 
- Atau custom dengan multi-router fallback 

**Hasil:** Bisa hemat 1-2% slippage per trade!

---

### 4. **Whale Copy Trading dengan AI Filter**
**Kenapa penting:** Daripada nebak token mana yang naik, lebih aman ikut whale yang sudah terbukti profit.

**Cara kerja:** 
1. Auto-discover whale wallets baru (levonchain data)
2. Filter: win rate >60%, hold time 5-30 menit, profit > $1k
3. AI analyze trade sebelum copy: cek market cap, liquidity, sentiment
4. Execute dengan position sizing lebih kecil dari whale (misal 20% dari whale amount)

**Implementasi di bot Anda:**
```typescript
const WHALE_CONFIG = {
  autoDiscover: true,
  minWhaleWinRate: 60,        // Minimal 60% win rate
  copySizePercent: 20,         // 20% dari size whale
  maxCopyPerDay: 5,
  aiGateEnabled: true          // AI filter sebelum copy
}
```

### 6. **Real-time Gas Optimizer**
**Kenapa penting:** Base fee memang murah, tapi tetap fluktuasi. Optimizer bikin Anda bayar fee minimal tanpa ketinggalan block.

**Fitur:**
- Prediksi gas price berdasarkan mempool congestion (pakai Sentio API) 
- 3 mode: Low/Medium/High (user bisa pilih)
- Auto retry dengan gas lebih tinggi jika transaksi pending

```typescript
// Gas recommendation dari mempool real-time

// Returns: { low: 0.002, medium: 0.005, high: 0.01 } GWEI
```

### 7. **Honeypot & Rugpull Auto-Detection (Lapisan Ganda)**
**Kenapa penting:** Meme coin banyak scam. Jangan sampai bot Anda beli token yang gak bisa dijual.

**API yang bisa dipakai:**
- **GoPlus Security API** (cek honeypot, tax, ownership) 
- **Honeypot.is** (fallback)
- **Deployer reputation check** (apakah si deployer pernah rug sebelumnya) 

**Checklist safety:**
```
✅ Bukan honeypot
✅ Sell tax < 15%
✅ Liquidity terkunci minimal 7 hari
✅ Deployer reputation score > 40
✅ Holders distribution tidak terpusat (>10% holder)
```

### 8. **Kill Switch & Emergency Stop**
**Kenapa penting:** Proteksi saat pasar crash atau bot error.

**Fitur:**
- **Emergency Stop Button** (jual semua posisi, stop semua aktivitas) 
- **Daily Loss Limit** (auto-stop jika loss hari ini > 10% modal)
- **Consecutive Loss Cooldown** (jika 3x rugi beruntun, pause 30 menit)
- **Telegram Kill Switch** (stop dari Telegram)

### 9. **Limit Order untuk Meme Coin**
**Kenapa penting:** Scalping butuh entry di harga tertentu, bukan market order terus.

Implementasi dengan memantau harga dan eksekusi saat harga mencapai level yang diinginkan.
